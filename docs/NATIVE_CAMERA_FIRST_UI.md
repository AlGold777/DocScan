# Спецификация нативного интерфейса Camera-First 📱✨

Версия спецификации: **2.0** (актуализировано для DocScan **v0.4.243**).

Интерфейс DocScan спроектирован по принципу **Camera-First** на чистых компонентах Android Views (без XML-разметки). Приложение ориентировано на скорость, отзывчивость при серийной съёмке и эргономику управления одной рукой.

---

## 1. Главный экран (Camera-First Viewport)

```
┌──────────────────────────────────────────────┐
│ [⋯ Меню]                        [Save PDF]  │  <-- Верхняя панель управления
│                                              │
│                                              │
│               ВИДОИСКАТЕЛЬ                   │
│                  КАМЕРЫ                      │
│                                              │
│        ┌────────────────────────────┐        │
│        │   Зеленый оверлей-полигон  │        │  <-- DocumentOverlayView (в режиме "Документ")
│        │     границ листа бумаги    │        │
│        └────────────────────────────┘        │
│                                              │
│                 (  ПУСК  )    [Документ]     │  <-- Затвор и переключатель режима
├──────────────────────────────────────────────┤
│ [☑] [103x75]  [☑] [103x75]  [☑] [103x75] ... │  <-- Лента эскизов (+17% размер)
├──────────────────────────────────────────────┤
│ [＋ Добавить]     [Выбрать все]    [🗑 Удалить]│  <-- Нижняя панель действий
└──────────────────────────────────────────────┘
```

### 1.1. Верхняя панель
* **`[⋯]` (Меню действий)**: открывает настройки, выбор папки назначения, принудительный запуск самопроверки и очистку рабочего пространства.
* **`[Save PDF]`**: кнопка экспорта выбранных страниц в Searchable PDF. Становится активной, когда в ленте выбрана хотя бы одна страница (`1..100`).

### 1.2. Область спуска затвора
* **Кнопка спуска («Пуск»)**: крупная круглая контрастная кнопка с тактильным откликом. Поддерживает одиночные нажатия и быстрое серийное сканирование (burst capture).
* **Кнопка режима «Документ»**:
  * Расположена с правой стороны от кнопки «Пуск».
  * Текстовая плашка-тумблер.
  * **Активное состояние**: зеленая подсветка `#22C55E`, белый текст. Включает фоновую детекцию контура документа и автовыравнивание перспективы на снимке.
  * **Неактивное состояние**: полупрозрачный фон `#33000000`, светло-серый текст. Съемка в обычном фото-режиме без обрезки.

### 1.3. Нижняя рабочая лента (Workspace Rail)
* **Бюджет высоты**: суммарная высота ленты и строки действий не превышает **175 dp** (фактическая высота ~166 dp), что оставляет максимум пространства для видоискателя камеры.
* **Карточки страниц**:
  * **Размер эскиза**: увеличен на **+17%** до **103 × 75 dp** (ранее 88 × 64 dp) для удобного чтения заголовков прямо в ленте.
  * **Чекбокс выбора**: расположен под каждым эскизом. Управляет включением конкретной страницы в сохраняемый PDF-файл.
  * **Плавный Drag & Drop**: удержание и перетаскивание карточки изменяет порядок страниц в итоговом документе.
* **Диспетчеризация жестов**:
  * **Одиночный тап**: переключение выбора страницы (чекбокс) / фокус.
  * **Двойной тап**: мгновенный переход в полноэкранное окно просмотра и редактирования (`showPageViewer`).

## 2. Окно просмотра и редактирования (Page Viewer & Editor)

Окно вызывается по двойному тапу на любой эскиз из нижней ленты и накладывается поверх главного экрана с эффектом размытия заднего плана.

```
┌────────────────────────────────────────────────────────┐
│  [X Закрыть]                      Страница 1 из 5      │
│ ────────────────────────────────────────────────────── │
│                                                        │
│               [   Большой просмотр   ]                 │
│               [  текущей страницы   ]                 │
│                                                        │
│ ────────────────────────────────────────────────────── │
│         ( 🔄 )          ( ✂️ )          ( 🎛️ )         │  <-- Иконки Rotate, Crop, Adjust
│ ────────────────────────────────────────────────────── │
│ ┌────────────────────────────────────────────────────┐ │
│ │ OCR: "Распознанный фрагмент текста документа..."    │ │  <-- Динамический скролл-бокс
│ └────────────────────────────────────────────────────┘ │      (от 42dp до 130dp)
│ ────────────────────────────────────────────────────── │
│     [ ReClick ]           [ ReOCR ]           [ 🗑️ ]   │  <-- Действия со страницей
└────────────────────────────────────────────────────────┘
```

### 2.1. Панель инструментов редактирования (`editToolbar`)
Все текстовые надписи с кнопок удалены. Инструменты представлены минималистичными круглыми кнопками с векторными иконками:
1. **Поворот (`ic_rotate_right`)**: циклический поворот страницы на 90° по часовой стрелке.
2. **Обрезка (`ic_crop`)**: переход в интерактивный режим коррекции 4 углов страницы с угловыми лупами-увеличителями.
3. **Настройка (`ic_tune`)**: регулировка контраста, экспозиции и фильтров бинаризации.

### 2.2. Динамический блок OCR (`ocrScroll`)
* Контейнер текста распознавания не имеет жестко фиксированной высоты.
* **Минимальная высота**: `42 dp` (компактная плашка при коротком тексте или отсутствии распознавания).
* **Максимальная высота**: `130 dp` (при большом объеме текста блок расширяется до 130 dp, после чего активируется внутренний скролл).
* Позволяет сохранить баланс между видимостью изображения документа и удобством чтения текста.

### 2.3. Кнопки действий (`viewerActions`)
* **`ReClick`**: быстрая пересъёмка текущего листа без изменения его позиции в списке страниц.
* **`ReOCR`**: повторный запуск распознавания текста (например, после поворота листа или смены языкового профиля).
* **`[ 🗑️ ]` (Корзина)**: удаление текущей страницы. Представлена контурной векторной иконкой `ic_delete_trash`.

## 3. Архитектура хоста диалогов (`InsetDialogHost`)

Для отображения модальных окон используется единый компонент `InsetDialogHost`:
* **Динамический размер панели**: панель рассчитывает свой размер как `WRAP_CONTENT` с ограничением максимальной высоты экрана за вычетом системных панелей (Status Bar и Navigation Bar).
* **Безопасные отступы (WindowInsets)**: гарантированный отступ не менее `20 dp` по бокам и `24 dp` сверху/снизу.
* **Размытие заднего плана (Backdrop Blur)**:
  * На Android 12+ (API 31+) применяется системный аппаратный `RenderEffect.createBlurEffect(20f, 20f, TileMode.CLAMP)`.
  * На устройствах Android 10–11 выполняется мгновенный захват экрана через `PixelCopy` с последующим быстрым масштабированием и софтверным блюром.

В версии 0.4.257 кнопка ⋮ в шапке открывает меню действий. Заголовок DocScan сохраняет вход в self-test по пяти нажатиям. Асинхронные результаты поворота и обрезки применяются только к исходному открытому просмотрщику, странице и поколению запроса.
