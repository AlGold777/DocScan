# Исправления практического peer-review

Исходная версия: 0.4.255. Ветка: `codex/practical-review-fixes`.
Исходные пользовательские изменения сохранены отдельно; тег `before-practical-review-fixes`.
Автообрезка без сохранения полного кадра принята владельцем и не меняется.

## 1. OCR-парсер
- [x] Каждый заголовок, подпись и строка учитывается ровно один раз.
- [x] Регрессионные проверки вложенных и самостоятельных заголовков.

## 2. Сохранение PDF
- [ ] Ошибки публикации и частичный комплект не дают сообщения об успехе.
- [ ] Свободное общее имя PDF/JPG, без перезаписи существующих файлов.
- [ ] OCR должен завершиться до заморозки; без изображения нельзя сохранить пустой текст.
- [ ] Текст импортированного PDF сохраняется целиком, длинные строки переносятся.
- [ ] Обычные сохранения получают локальный экспорт и запись в «Недавние».
- [ ] Выбранная SAF-папка используется явно; без неё — Download/DocScan.

## 3. Съёмка и редактор
- [x] Доступ к выбору папки, языку и восстановлению через интерфейс.
- [x] Рамка, поворот и режим документа фиксируются перед съёмкой.
- [x] Лимиты ручной обрезки согласованы с загрузкой изображения.
- [x] Сохранение настроек выполняется из исходного файла с разрешением до экспортного предела 3000 px; уменьшенное превью не становится оригиналом.
- [x] Запоздалый результат редактирования не подменяет другую страницу.

## 4. Очереди и итоговая проверка
- [ ] Новый язык/версия страницы заменяют предыдущую задачу OCR; ожидание сообщает ошибки.
- [ ] Каждая пачка импорта получает неизменяемый идентификатор.
- [ ] JVM-регрессии, компиляция instrumentation, debug/release APK в dist.
- [ ] Сценарии на устройстве — при наличии подключённого Android.

Простые изолированные изменения делегируются агентам. Запуск тестов, сборок и анализ проверок — GPT-6 Luna/high. Основной агент интегрирует сохранение и UI. Каждая законченная группа — отдельный коммит с версией и документацией.
