## Границы проверки

Автоматические проверки камеры не заменяют съёмку реальной бумаги на телефоне. Качество автообрезки при бликах, смазе и сложном фоне требует отдельной проверки на физическом устройстве. Полный кадр до автоматической обрезки по решению владельца не сохраняется.
