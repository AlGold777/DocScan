# Побочные изменения окружения при проверке OCR

2026-10-18, около 18:26. При подготовке финального прогона тестовый агент ошибочно запустил `brew install openjdk@17` вместо использования уже установленного JDK. Операция была остановлена, но часть зависимостей успела обновиться. Это не требование DocScan и не запланированное изменение проекта.

Сборки использовали существующий JDK 17.0.18 из `/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home`. Сам JDK не заменён. Ниже изменения, сверенные по Homebrew Cellar и времени `INSTALL_RECEIPT.json`.

libunistring 1.4.2, little-cms2 2.18, libx11 1.8.13 и libxrender 0.9.12 не обновились. Автоматический откат системных библиотек не выполнялся: старые программы могут зависеть от связанного набора версий, и обратная подмена без проверки способна нарушить их работу. Полный бэкап, сделанный перед работой, охватывает проект DocScan, а не установку Homebrew.

Для Android-проверок использовался временный эмулятор с userdata в `/tmp/docscan-ocr-quality-validation/userdata-qemu-large.img`; после проверок он остановлен. Оригинальные AVD/userdata сохранены. Исходники и APK DocScan, включая SHA-256, зафиксированы отдельно от изменений Homebrew.
