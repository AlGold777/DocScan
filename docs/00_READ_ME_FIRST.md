## 1. Порядок чтения активной документации

Для разработчиков, архитекторов и ИИ-агентов, работающих с текущей кодовой базой:

1. [**`../README.md`**](../README.md) — обзор проекта, стек технологий, модульная структура, инструкции по сборке.
2. [**`ARCHITECTURE.md`**](ARCHITECTURE.md) — актуальная системная архитектура: модули `:app` и `:core`, транзакционное хранилище SQLDelight, модель неизменяемости артефактов (`FileArtifactRepository`), потоки и защита от OOM.
3. [**`DOCUMENT_DETECTION_AND_RECTIFICATION.md`**](DOCUMENT_DETECTION_AND_RECTIFICATION.md) — алгоритмы OpenCV: поиск контуров документа в реальном времени, отрисовка полигона `DocumentOverlayView`, перспективная коррекция (гомография).
4. [**`NATIVE_CAMERA_FIRST_UI.md`**](NATIVE_CAMERA_FIRST_UI.md) — спецификация интерфейса: главный экран Camera-First, нижняя лента эскизов 103×75 dp (+17%), окно просмотра/редактирования, иконки без текста, кнопки `ReClick`/`ReOCR`/`🗑️`, динамический скролл OCR и `InsetDialogHost`.
5. [**`OCR_AND_SEARCHABLE_PDF.md`**](OCR_AND_SEARCHABLE_PDF.md) — оптическое распознавание Tesseract 4/5, нативный C++ `ResultIteratorLayoutExtractor`, генерация двухслойного Searchable PDF через Apache PDFBox с невидимым текстовым слоем.
6. [**`AUDIT_INVARIANTS.md`**](AUDIT_INVARIANTS.md) — обязательные системные инварианты целостности данных, транзакций и файлового хранилища.
7. [**`../CHANGELOG.md`**](../CHANGELOG.md) — хронология релизов и список всех изменений до версии **0.4.243**.

* ✅ **Фаза 1: Spike Harness (Завершена)**: проведены замеры производительности памяти, SQLite-транзакций, CameraX и PDFBox на стенде `DocScanSpikeHarness`.

* ✅ **Фаза 4: Интеграция редактора и распознавания (0.4.238..0.4.242)**: разделение одиночного/двойного тапа, инструменты Rotate/Crop, нативный экстрактор структуры `ResultIteratorLayoutExtractor` с устранением утечек C++.
* 🚀 **Фаза 5: Live Document Mode & UI Polish (Текущая версия 0.4.243)**:
  * Потоковая детекция контура листа в видоискателе камеры с зеленым оверлеем (`DocumentOverlayView`).
  * Автоматическое гомографическое выпрямление документа при съемке.
  * Увеличение превью на +17%, иконки без текста, динамический блок OCR.
