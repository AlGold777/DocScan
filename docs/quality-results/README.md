# OCR validation results

`synthetic_ocr_benchmark.csv` contains the twelve generated fixture baselines plus preprocessing, page-segmentation, model, and 12 MP decode probes. The 12 fixture truth strings are synthetic; these rows are not camera-scan evidence. The crop probe compares the former 4 MP decode (2000×1500) with the current 6 MP precise decode (2896×2172).

`funsd_ocr_metrics.csv` records the first ten lexicographically sorted FUNSD testing pages. Recall uses NFKC-normalized, case-folded token multisets; token order is not scored because annotation order is not a reading-order ground truth. Numeric recall counts annotated/predicted tokens that contain a digit. These 1990s scanned forms contain small type, handwriting, and noisy fax marks; they are not phone-camera photographs.

`spanish_language_diagnostic.csv` captures the generated Spanish PNG/JPEG outputs before the `.264` language-routing fix. AUTO selected `rus+eng` on these Spanish-only pages and preserved 1 of 6 diacritic tokens; explicit Spanish models preserved 5 of 6, with `pingüino` read as `pinguino` by every model set. CER ignores whitespace, matching `OcrQualityTestSupport.cer` in instrumentation. `spanish_language_diagnostic_0.4.264.csv` records the after result: AUTO selected `spa+eng` and preserved all supported accent tokens on both PNG and JPEG; the only remaining CER is the model's missing diaeresis in `pingüino`.
