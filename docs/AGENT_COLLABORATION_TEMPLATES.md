# Шаблоны взаимодействия Codex и Antigravity

Версия 1.0 · 2026-09-20.
Применять вместе с `AGENT_COLLABORATION_PROTOCOL.md`.
Это переносимые формы, не задания на изменение конкретного проекта.
Заполнять в одном рабочем документе этапа; не копировать историю каждого раунда целиком.

## 1. Сообщение для начала работы любого из агентов

```text
Прочитай приложенный AGENT_COLLABORATION_PROTOCOL.md и следуй ему.
Твоя роль: [ревьюер / исполнитель].
Контракт этапа и актуальный чеклист: [ссылки или вложения].
Последний согласованный пакет замечаний и передача: [ссылки].

Не ограничивайся diff и не исправляй только отдельные примеры.
Новая находка требует поиска класса и единого списка аналогов.
Приёмку веди по P/F/C/E, регрессионным тестам и полному прогону этапа.
Отдельно указывай исполненные проверки и непроверенные утверждения.
Если исходные материалы недоступны, не заявляй, что выполнил аудит.
```

## 3. Поэлементный чеклист

| ID | Требование / источник | Элемент и условие обязательности | P | F | C: независимый источник | E | Реализация: версия/место | Тесты P/F/C/E | Исполнение/evidence | Вердикт |
|---|---|---|---|---|---|---|---|---|---|---|
| INV-… | … | … | TODO | TODO | TODO | TODO | … | … | … | … |

Для каждого свойства записать ожидаемую проверку и статус, а не только галочку.
N/A требует основания. Не заменять все вложенные поля одной строкой «JSON валиден».
Один параметризованный тест может покрывать несколько явно перечисленных элементов.

## 4. Консолидированный пакет ревью — до фикса

```text
Контракт / проверенная версия:
Область сквозного поиска и что ещё не обследовано:
Проверено самостоятельно: [код / команды / интеграция / evidence].
Не проверено:

Класс дефекта F-…:
  Инварианты и категории P/F/C/E:
  Уровень доказательства: [воспроизведено / вывод из кода / гипотеза].
  Нарушение и последствия:
  Все найденные места: [список с версиями/местами].
  Защищённые аналоги и обоснованные исключения:
  Обобщённое требование к исправлению:
  Обязательные отрицательные тесты и положительный контроль:
  Ожидаемая ошибка, отсутствие побочных действий, сохранённые доказательства:

Единый порядок исправлений и зависимости:
Предварительная область следующей приёмки:
```
