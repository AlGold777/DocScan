# DocScan 📄⚡

Высокопроизводительный, полностью автономный Android-сканер документов с нативным интерфейсом **Camera-First**, обработкой изображений через **OpenCV**, распознаванием текста (**Tesseract OCR**) и генерацией структурированных файлов **Searchable PDF** (Apache PDFBox).

Приложение разработано без использования тяжелых фреймворков и декларативных XML-макетов — весь интерфейс спроектирован на чистом Kotlin Android Views с жестким контролем жизненного цикла памяти, частоты кадров и целостности данных.

---

## 🚀 Ключевые возможности

### 1. Камера и Live-детекция документов («Режим Документ»)
* **Camera-First UX**: видоискатель камеры всегда активен на главном экране; съёмка одиночных кадров и серийная съёмка без задержек.
* **Минималистичный верхний бар**: лаконичный заголовок `DocScan` слева (с возможностью входа в диагностический Self-Test по 5 тапам) и кнопка быстрого сохранения `Save` справа. Устаревшие модальные меню удалены в пользу прямого жестового управления на главном экране.
* **Повышенное разрешение анализа (1280×960) и Zero-Copy конвейер**:
  * Кадры анализируются в высоком разрешении 1280×960 с контролируемым внутренним даунскейлом до 720 px.
  * Прямой захват нативного буфера `imageProxy.planes[0].buffer` в `Mat(CV_8UC4)` полностью исключает промежуточные аллокации `Bitmap` и снижает нагрузку на GC.
* **Автоматическое определение границ**: фоновый поток `CameraX ImageAnalysis` (с троттлингом ~100 мс) обрабатывает кадры через OpenCV:
  * Единая карта границ (Otsu-адаптивный Canny + морфологический градиент) и HSV-карта бумаги с заливкой полостей (`fillHoles`), исключающая искажения от внутреннего текста документа.
  * Бинарный поиск параметра $\varepsilon$ в `approxPolyDP` и взвешенный фотометрический скоринг кандидатов (`edgeSupportScore`, `ringContrastScore`, `borderPenalty`, параллельность, соотношение сторон).
  * **Субпиксельное уточнение граней (`Imgproc.fitLine`)**: МНК-фиттинг прямых вдоль граней с поиском их точных геометрических пересечений устраняет ступеньки и шумы дискретизации.
  * **HoughLinesP-фоллбек**: надежное обнаружение границ листа при низком контрасте (белый лист на светлом столе/скатерти).
* **Адаптивная временная фильтрация (`QuadTemporalFilter`)**: EMA-сглаживание контура с защитой от скачков (двухкадровое подтверждение выбросов) и удержанием рамки при кратковременных пропусках (3 кадра).
* **Нативная проекция координат CameraX**: объединение камеры и анализатора через общий `ViewPort` и проекция координат через `CoordinateTransform` без ручного поворота буфера.
* **Зелёный полигон-оверлей (`DocumentOverlayView`)**: векторная отрисовка контура документа с угловыми маркерами в реальном времени прямо поверх видоискателя.
* **WYSIWYG-коррекция перспективы (Keystone Warp)**: при включенном режиме «Документ» после спуска затвора снимок автоматически выравнивается по зафиксированному `quadForCapture` с учетом EXIF-ориентации сенсора (или полным детектом в качестве фоллбека).
* **Переключатель режима**: кнопка «Документ» с динамической индикацией состояния расположена справа от кнопки спуска затвора («Пуск»).

### 2. Нижняя рабочая лента (Workspace Rail)
* **Горизонтальная лента эскизов**: карточки страниц с быстрой асинхронной подгрузкой превью из локального кэша.
* **Увеличенные эскизы**: превью страниц увеличены на **+17%** (103×75 dp) для комфортного визуального контроля качества.
* **Интерактивность**:
  * Одиночный тап по чекбоксу/эскизу — выбор страницы для сохранения в PDF.
  * Двойной тап по эскизу — открытие полноэкранного окна детального просмотра и редактирования страницы.
  * Плавное перемещение (Drag & Drop) страниц для изменения их порядка в итоговом документе.

### 3. Окно детального просмотра и редактирования (Page Viewer & Editor)
* **Эргономичная компоновка с боковыми панелями**:
  * **Левая панель (инструменты редактирования)**:
    * 🔄 **Поворот (Rotate)**: поворот страницы с шагом 90° с обновлением превью и сохранением промежуточного состояния.
    * ✂️ **Обрезка (Crop / Resize)**: ручная коррекция границ документа: свободное перемещение 4 углов и 4 рёбер с визуальными маркерами-манипуляторами и перспективной трансформацией.
    * 🎛️ **Настройка (Adjust)**: яркость, контраст, ч/б и бинаризация.
  * **Правая панель (быстрые действия со страницей)**:
    * `ReClick` — быстрая пересъёмка текущей страницы с заменой артефакта.
    * `ReOCR` — повторный запуск оптического распознавания текста.
    * 🗑️ — удаление текущей страницы (аккуратная контурная иконка корзины).
* **Увеличенный размер просматриваемого эскиза**:
  * Высота главного превью увеличена на **+17%** (с 270dp до 316dp), что за счёт пропорционального масштабирования (`FIT_CENTER` / `adjustViewBounds`) расширило и ширину, дав прирост полезной площади на ~37%.
* **Минималистичный интерфейс без лишних кнопок**:
  * Удалена избыточная строка кнопки «Отмена» — закрытие диалога реализовано через верхнюю кнопку «✕», тап по затемненному фону или системный жест «Назад».
* **Расширенная зона просмотра OCR-текста**:
  * Нижний край окна диалога опущен ближе к нижней полосе эскизов (с сохранением безопасного отступа 20dp).
  * Максимальная высота блока распознанного текста OCR (`ocrScroll`) расширена со 130dp до 160dp с внутренней прокруткой и возможностью выделения текста.

### 4. Каноническая карта страницы (OcrLayout / DOCSCAN-OCR-LAYOUT/2) и Searchable PDF
* **Автономный OCR (Tesseract 4/5)**: локальное распознавание текста без обращения к сети на базе `tesseract4android` с моделями русского (`rus`), английского (`eng`) и испанского (`spa`) языков.
* **Автоматическое определение языка (`LangDetect`) и профили**:
  * Двухпроходный конвейер OCR в режиме `Авто`: первый проход (`rus+eng`), затем при обнаружении испанского текста (стоп-слова, диакритика `ñ`, `á`, `é`, `í`, `ó`, `ú`, `ü`, `¿`, `¡`) — автоматический второй проход (`spa+eng` или `rus+spa+eng`).
  * Ручной выбор языка в меню «Страницы и действия» (`Авто`, `Русский + English`, `Español + English`, `Русский + Español + English`) и меню «Распознать заново с языком…» по долгому тапу на `ReOCR`.
* **Парсер hOCR и естественный порядок чтения (`HocrParser`)**:
  * Извлечение структуры документа через стандартизированный `hOCR` без искусственной сортировки блоков по координатам.
  * Фильтрация нетекстовых зон (`ocr_photo`, `ocr_separator`), санитайзинг строк (`sanitizeOcrText`) с удалением невидимых/управляющих символов и декодированием HTML-сущностей, клампинг координат (`clampBox`).
* **Каноническая модель документа (`OcrLayout`)**:
  * Иерархия: Блоки $\rightarrow$ Параграфы $\rightarrow$ Строки $\rightarrow$ Слова с пиксельными координатами `Bx(l, t, r, b)`.
  * Формирование связного текста `toPlainText()` с естественными абзацными отступами (`\n\n`) и переводами строк (`\n`).
  * Сериализация в SQLite (`Recognition.payload`) в компактном формате `DOCSCAN-OCR-LAYOUT/2\n{...}` с сохранением языка (`lang`) и полной обратной совместимостью с V1 и сырым текстом.
* **Двухслойный отказоустойчивый Searchable PDF (Apache PDFBox)**:
  * Встроенный шрифт `NotoSans-Regular.ttf` из `assets/fonts/` (полная независимость от системных шрифтов Android).
  * Быстрая кэшированная валидация глифов (`PDType0Font.safeText`) для защиты от крэшей при редких символах.
  * Построчный рендеринг слов без падений при искаженной геометрии и автоматическое безопасное масштабирование геометрии (`scaledTo`) при несоответствии разрешений.

### 5. Надежность и хранилище данных
* **Транзакционное хранилище**: SQLDelight (SQLite) со строгой схемой данных и версионированием миграций (версия 11).
* **Изолированный репозиторий артефактов (`FileArtifactRepository`)**:
  * Исходные кадры камеры (`original.jpg`) никогда не перезаписываются и сохраняются как неизменяемые мастер-копии.
  * Все правки создают версионированные производные файлы (`edit_draft_*.jpg`).
  * Безопасная очистка временных файлов (`CleanupArbiter`) без риска удаления используемых страниц.

### 6. Экспорт через SAF и повторное редактирование сохраненных PDF
* **Диалог сохранения**: умное предложение имени (`OutputBasenameSuggester`), настраиваемые префиксы названий файлов с выпадающим списком и диалогом редактирования (`FilePrefixPreferences`, `PrefixEditDialog`), независимые тумблеры OCR-слоя и изображений JPG:
  * `OCR` + `JPG`: полноценный Searchable PDF с визуальным сканом и наложенным текстовым поисковым слоем + экспорт файлов JPG.
  * `OCR` без `JPG`: чистый текстовый PDF с видимым напечатанным текстом OCR без внедрения растровой картинки (минимальный вес документа).
  * `JPG` без `OCR`: графический PDF, состоящий только из изображений страниц.
* **Редактирование существующих PDF**: открытие сохраненных PDF (`SavedPdfPageRenderer`), переупорядочивание, удаление, добавление новых страниц и сохранение новой редакции без перезаписи оригинала (`SavedPdfEditSession`).

## 🏗️ Архитектура проекта

Проект разделен на два основных Gradle-модуля:

```
DocScan/
├── app/                  # Android Application модуль (UI, CameraX, OpenCV, Activities)
│   ├── src/main/kotlin/app/docscan/android/
│   │   ├── ProductActivity.kt           # Главный экран (Камера, Лента, Интерактивные диалоги)
│   │   ├── DocumentOverlayView.kt       # Оверлей реального времени для полигона документа
│   │   ├── QuadTemporalFilter.kt        # Адаптивный EMA-фильтр контура с защитой от скачков
│   │   ├── DocumentCropProcessor.kt     # OpenCV Canny/Contour детекция и homography warp
│   │   ├── InsetDialogHost.kt           # Хост диалоговых окон с безопасными отступами и размытием
│   │   ├── PrefixEditDialog.kt          # Диалог управления и inline-редактирования префиксов
│   │   ├── PrefixDropdownComponents.kt  # Кастомный селектор и логика подстановки префиксов
│   │   ├── FilePrefixPreferences.kt     # Постоянное хранение префиксов (SharedPreferences)
│   │   ├── WorkspaceHomeAdapter.kt      # RecyclerView адаптер нижней ленты с Drag&Drop
│   │   ├── WorkspaceThumbnailLoader.kt  # Двухуровневый кэш и пул потоков загрузки эскизов
│   │   ├── TesseractOcrAdapter.kt       # Фоновое распознавание и управление моделями tessdata
│   │   └── SearchablePdfWriter.kt       # Генератор PDF с текстовым слоем через Apache PDFBox
│   ├── src/main/assets/fonts/           # Встроенный шрифт NotoSans-Regular.ttf для PDF слоя
│   └── src/main/res/drawable/           # Векторные иконки интерфейса
│
├── core/                 # Чистый Kotlin/JVM модуль (бизнес-логика, база данных, модели)
│   ├── src/main/kotlin/app/docscan/core/
│   │   ├── ocr/                         # OcrLayout, HocrParser, OcrSanitize (санитайзинг, клампинг)
│   │   ├── store/                       # StateStore, RecognitionPayloadCodec (/2), MVI-команды
│   │   ├── artifact/                    # FileArtifactRepository, управление файлами
│   │   ├── edit/                        # Модели поворота, обрезки, 4-точечных полигонов
│   │   └── export/                      # Правила именования файлов и резолверы коллизий
│   └── src/main/sqldelight/             # SQL-схема и миграции базы данных (1..11.sqm)
│
├── docs/                 # Архитектурная и пользовательская документация
└── dist/                 # Готовые сборки release APK
```

## 🛠️ Стек технологий

| Компонент | Технология / Библиотека | Назначение |
|---|---|---|
| **Язык** | Kotlin 2.1 | Типобезопасная асинхронная кодовая база |
| **Камера** | AndroidX CameraX 1.4 | Захват кадров, сессионная съёмка, ImageAnalysis |
| **Компьютерное зрение** | OpenCV 4.10 (Android SDK) | Детекция границ листа, Canny, findContours, homography warp |
| **OCR** | Tesseract4Android 4.7 (Tesseract 5 C++) | Распознавание текста на устройстве (rus, eng) |
| **Генерация PDF** | Apache PDFBox Android (TomRoush 2.0.27) | Сборка Searchable PDF с невидимым текстовым слоем |
| **База данных** | SQLDelight 2.0 + Android SQLite | Транзакционное хранение состояния рабочего пространства |
| **Асинхронность** | Kotlin Coroutines + ThreadPoolExecutors | Фоновое выполнение I/O, OCR и кодирования изображений |
| **UI** | Pure Android Views (0% XML layouts) | Кастомные программные View, InsetDialogHost, TouchDelegates |

## 📦 Сборка и установка

### Системные требования:
* JDK 17+
* Android SDK (API 34/35/36, minSdk 29)
* Gradle 8.13 (через `./gradlew`)

### Сборка Debug APK:
```bash
./gradlew assembleDebug
```
Файл сборки: `app/build/outputs/apk/debug/DocScan-debug-<версия>.apk`

### Сборка Release APK:
```bash
./gradlew assembleRelease
```
Файл сборки: `dist/DocScan-release-<версия>.apk` и `dist/DocScan-release.apk`

### Практические исправления редактора (0.4.257)
Кнопка ⋮ в верхней панели открывает выбор папки, язык OCR и восстановление экспорта. В меню можно вернуться к Download/DocScan. Рамка автообрезки фиксируется в момент нажатия затвора. Ручная обрезка и сохранение настроек используют изображение с разрешением до 3000 px по длинной стороне; уменьшенный предпросмотр не заменяет источник при сохранении. Полный кадр до автоматической обрезки по принятому поведению не сохраняется.
